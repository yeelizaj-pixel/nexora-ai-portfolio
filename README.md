# NEXORA AI — Portafolio Web Profesional

## Descripción del proyecto

NEXORA AI es un portafolio web personal desarrollado como proyecto académico de Ingeniería en Sistemas. Su objetivo es presentar proyectos, tecnologías y conocimientos de una manera moderna, interactiva y adaptable a diferentes dispositivos.

El diseño combina una estética tecnológica con una interfaz oscura, una alternativa de modo claro y un efecto animado de lluvia digital inspirado en Matrix.

## Objetivos

- Crear un portafolio profesional utilizando tecnologías web.
- Practicar HTML5, CSS3, Bootstrap 5 y JavaScript.
- Implementar interacciones dinámicas y filtros para proyectos.
- Diseñar una interfaz adaptable a computadoras, tabletas y teléfonos.
- Publicar el proyecto mediante GitHub Pages.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS3:** estilos, colores, animaciones y diseño adaptable.
- **Bootstrap 5:** componentes y diseño responsive.
- **JavaScript:** modo oscuro/claro, filtros de proyectos, animación Matrix y validación del formulario.
- **Bootstrap Icons:** iconos de navegación, tecnologías y redes sociales.
- **GitHub:** almacenamiento y control del proyecto.
- **GitHub Pages:** publicación del sitio web.

## Funcionalidades principales

- Menú de navegación.
- Presentación personal con fotografía.
- Sección de tecnologías.
- Galería de nueve proyectos de ejemplo, organizados en Web, App y Diseño.
- Filtros interactivos por categoría.
- Sección de experiencia.
- Videos integrados de YouTube.
- Efecto Matrix animado en el fondo.
- Alternancia entre modo oscuro y claro.
- Formulario de contacto con validación de campos.
- Iconos de redes sociales y botón para volver al inicio.

**Nota:** el formulario requiere configurar un servicio de correo para que los mensajes se envíen realmente por email.
